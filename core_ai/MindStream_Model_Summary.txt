MindStream: Real-Time Emotion-Powered Video Generation

MindStream is a smart emotion-aware break assistant designed to help desktop users stop prolonged doomscrolling and regain focus.

HOW THE SYSTEM WORKS

1. Facial Emotion Detection

After the user has been browsing for a long time, MindStream asks:

“Want a quick snap check-in?”

With the user’s permission, it records a short webcam clip of about three seconds. A facial emotion recognition model trained using the FER2013 dataset analyzes the user’s face.

The FER2013 dataset contains 35,887 facial images with seven emotion labels:

- Angry
- Disgust
- Fear
- Happy
- Sad
- Surprise
- Neutral

The model learns facial patterns. For example:

- A smiling face may be classified as happy.
- Wide eyes and an open mouth may be classified as surprise.
- Lowered eyebrows may be classified as angry.
- Drooping facial features may be classified as sad.

For use inside MindStream, the seven facial emotions can be converted into five simpler categories:

- Angry → Frustrated
- Sad → Fatigued
- Fear → Anxious
- Surprise → Distracted or alert
- Happy → Neutral or positive
- Neutral → Neutral
- Disgust → Frustrated

An example model output is:

{
  "emotion": {
    "label": "frustrated",
    "confidence": 0.82
  }
}

This means that the model believes the user is frustrated with 82% confidence.

MindStream uses these five final emotion categories:

- Frustrated
- Fatigued
- Distracted
- Anxious
- Neutral


2. Scrolled Content Classification

MindStream also tries to understand what type of content the user is viewing.

The AG News dataset contains around 120,000 articles divided into four categories:

- World
- Sports
- Business
- Science and Technology

A model trained using this dataset can classify the type of content being viewed. Inside MindStream, this information can be converted into practical browsing categories such as:

- Entertainment
- Coding
- Social media
- Research
- Shopping
- General browsing

MindStream can also collect limited local context, including:

- Current website domain
- Current page title
- Content category
- Time of day
- Browser session duration
- Idle time

It does not need to collect full browsing history, keystrokes, or mouse movements.

Example context:

Emotion: Frustrated
Website: youtube.com
Content type: Entertainment
Session duration: 47 minutes
Time: Evening


3. Text Emotion Classification

The GoEmotions dataset contains around 58,000 Reddit comments labeled with 27 emotions.

A model trained using GoEmotions can identify emotions in text, including:

- Anger
- Fear
- Sadness
- Excitement
- Confusion
- Disappointment
- Nervousness
- Relief

For example, the sentence:

“I have been trying to finish this for hours.”

may be classified as frustration or disappointment.

These detailed emotions can be converted into MindStream’s five simpler emotion categories:

- Nervousness → Anxious
- Annoyance → Frustrated
- Disappointment or tired language → Fatigued
- Confusion → Distracted
- Emotionally calm text → Neutral

This component can be useful if MindStream receives a short typed check-in, page text, captions, or other written content.


COMPLETE WORKFLOW

Step 1: Detect a possible distraction cycle

The browser extension tracks how long the user has been active. After a certain period, it sends a notification asking whether the user wants a quick emotional check-in.

Step 2: Ask for permission

The camera only activates after the user gives permission.

Step 3: Capture a short clip

MindStream records a short webcam clip of approximately three seconds.

Step 4: Analyze facial emotion

The facial emotion model examines the clip and predicts an emotion with a confidence score.

Example:

Emotion: Sad
Confidence: 72%

MindStream may convert sad into fatigued.

Step 5: Understand the browsing context

The system checks information such as:

- Website: YouTube
- Category: Entertainment
- Session time: 50 minutes
- Time: Evening

Step 6: Combine emotion and context

MindStream now understands something like:

“The user appears fatigued and has been scrolling entertainment content for almost an hour.”

Step 7: Generate a personalized script

The emotion and browsing context are sent to Gemini. Gemini creates a short personalized focus-reset message.

Example:

“You have been here for a while, and you look a little drained. Step away from the screen, stretch your shoulders, and take three slow breaths.”

Step 8: Convert the script into speech

A text-to-speech model converts the generated script into natural-sounding audio.

Step 9: Generate the reset video

MindStream creates a short vertical video by combining:

- A calm background video
- Generated voice
- Ambient background sound
- Subtitles
- Emotion-based personalization

Step 10: Notify the user

The video is generated in the background. When it is ready, MindStream sends a notification such as:

“Your snap is ready — wanna have a look?”

The user can then open the video and take a short mental break.

FINAL SUMMARY

MindStream is not only an emotion-detection model. It is a complete system that:

1. Detects the user’s facial emotion.
2. Understands emotion from text when available.
3. Classifies the type of content being viewed.
4. Uses browsing context such as time and session duration.
5. Generates a personalized script.
6. Converts the script into speech.
7. Combines speech, video, music, and subtitles.
8. Delivers a short video intended to help the user stop doomscrolling and regain focus.

In one sentence:

MindStream notices how the user feels, understands what they are doing, and creates a personalized video intervention to help them take a break and refocus.
